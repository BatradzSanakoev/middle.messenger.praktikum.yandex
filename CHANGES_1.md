## Недавние изменения

### Страница профиля

- **profile.hbs** — все инпуты переписаны с использованием компонента `{{#input}}...{{/input}}`
- **profile.hbs** — удалён дублирующий блок "Режим изменения данных", оставлен один блок с инпутами
- **profile.hbs** — инпуты заблокированы по умолчанию (`disabled=true`), разблокируются при нажатии "Изменить данные"
- **profile.hbs** — кнопка "Сохранить" скрыта по умолчанию
- **profile.hbs** — блок паролей скрыт по умолчанию, показывается при нажатии "Изменить пароль"
- **profile.hbs** — удалена кнопка "Отмена"
- **profile.hbs** — атрибуты `name` инпутов приведены к формату API: `first_name`, `second_name`, `display_name`, `old_password`, `new_password`, `confirm_password`
- **profile.ts** — логика: при нажатии "Изменить данные" инпуты разблокируются, при "Сохранить" — блокируются обратно
- **profile.ts** — логика: "Изменить пароль" скрывает блок данных и показывает блок паролей
- **profile.ts** — логика: "Сохранить" скрывает блок паролей и возвращает блок данных
- **profile.module.css** — добавлены стили `.dataValue:disabled` (серый текст, курсор not-allowed)
- **handlebars-helpers.ts** — в хелпер `input` добавлена поддержка `disabled`
- **handlebars-helpers.ts** — в хелпер `chatItem` добавлена передача `alt` для accessibility
- **input.hbs** — добавлена поддержка атрибута `disabled`
- **chat-item.hbs** — добавлен динамический атрибут `alt` для аватара чата
- **chats.ts** — добавлено поле `alt` для всех чатов, заполнены описания
- **global.css** — удалён глобальный класс `.hidden`, добавлены CSS-переменные для всех цветов проекта
- **Все .module.css файлы** — все цвета заменены на CSS-переменные (`--color-black`, `--color-white`, `--color-gray`, `--color-light-gray`, `--color-hover-bg`, `--color-overlay`, `--color-modal-overlay`)
- **profile.hbs** — атрибуты `for` у label и `name` у инпутов приведены к единому формату (совпадают)
- **profile.hbs** — удалены все `id` у инпутов
- **profile.hbs** — всем инпутам добавлены `id`, совпадающие с `for` у соответствующих `label` (email, login, first_name, second_name, display_name, phone, old_password, new_password, confirm_password)
- **handlebars-helpers.ts** — в хелпер `input` добавлена передача опционального параметра `id`
- **input.hbs** — добавлена поддержка опционального атрибута `id` для `<input>`
- **input.ts** — в класс `Input` добавлен опциональный параметр `id?: string`

- Настроен **TypeScript** со строгими настройками
- Создана базовая структура проекта

### Текущее состояние

#### Настроенная сборка

- **Vite** (v8.3.0) — сборщик с поддержкой HMR
- **TypeScript** (v6.0.2) — строгая типизация
- **PostCSS** — обработка стилей с CSS Modules
- **Handlebars** (v4.7.9) — шаблоны для UI

#### Исправления

- **Исправлен HMR (hot reload)** — изменён скрипт запуска в `package.json` с `"start": "npm run build && npm run preview"` на `"start": "npm run build && vite"` для корректной работы изменений в реальном времени
- **Добавлена секция engines** в `package.json` — указание версии NodeJS `>=18.0.0`
- **Добавлен `.gitignore`** — исключены автогенерируемые файлы CSS Modules

#### Компоненты

- **Input** — компонент поля ввода
  - Нижний бордер с цветом `var(--color-black)`
  - При фокусе бордер становится серым `var(--color-gray)`
  - Поддержка ошибки (серый текст `var(--color-gray)`)
  - Поддержка `disabled` — серый текст, курсор not-allowed
  - Внешние отступы убраны, отступы задаются через flex-gap родителя

- **Button** — кнопка с текстом
  - Всегда одинаковый стиль (чёрный фон `var(--color-black)`, белый текст `var(--color-white)`)
  - Меняющийся текст через проп `text`
  - Фиксированная ширина `12rem`
  - Без border-radius

- **Link** — компонент ссылки
  - Всегда одинаковый стиль (чёрный текст `var(--color-black)`, без подчёркивания)
  - Меняющийся текст через проп `text`
  - Ссылка через проп `href`
  - Без border-radius

#### Handlebars-хелперы

- **button** — рендерит компонент Button из HBS-шаблона
- **input** — рендерит компонент Input из HBS-шаблона
- **link** — рендерит компонент Link из HBS-шаблона
- **chatItem** — рендерит элемент чата из HBS-шаблона
- **profileAvatar** — рендерит аватар профиля из HBS-шаблона
- **modal** — рендерит модалку из HBS-шаблона

#### Стили проекта

- **CSS-переменные** — все цвета вынесены в `:root` (`--color-black`, `--color-white`, `--color-gray`, `--color-light-gray`, `--color-hover-bg`, `--color-overlay`, `--color-modal-overlay`)
- **Минималистичный стиль** — белый фон, черный текст, серые акценты
- **Шрифт Caveat** — подключен глобально через Google Fonts
- **Без border-radius** — все элементы прямоугольные
- **Глобальный сброс** — margin: 0, padding: 0, box-sizing: border-box
- **Базовый размер шрифта** — `1.25rem`
- **Высота страницы** — `html` и `body` имеют `height: 100%` для корректного центрирования
- **Алиасы импортов** — `@shared`, `@pages`, `@features`, `@helpers`, `@styles`, `@init`

#### Семантика

- **Семантические теги** — используются `<main>`, `<aside>`, `<form>`, `<button>`, `<ul>`, `<li>`, `<h1>`, `<nav>`, `<label>`
- **Формы** — все формы обернуты в `<form>` с `onsubmit="event.preventDefault()"`
- **Списки** — список чатов реализован через `<ul>` и `<li>`
- **Заголовки** — все заголовки обернуты в `<h1>`
- **Основной контент** — обернут в `<main>`
- **Навигация** — реализована через `<nav>` с `<ul>` и `<li>`
- **Лейблы** — поля ввода обернуты в `<label>` с атрибутом `for`

#### Навигация

- **Главная страница** — навигация со ссылками на все страницы проекта
- **Роутинг** — переключение страниц через hash (`#login`, `#register`, `#chat`, `#profile`, `#404`, `#500`)
- **Список страниц** — авторизация, регистрация, чаты, профиль, 404, 500
